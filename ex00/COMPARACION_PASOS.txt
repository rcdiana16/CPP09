5️⃣ Busco el precio correcto 🔍
================================================================================
FUNCIÓN: getExchangeRate()
UBICACIÓN: BitcoinExchange.cpp (líneas ~170-185)
QUÉ HACE:
  - Busca la fecha exacta en _database
  - Si no existe, busca la fecha MÁS CERCANA ANTERIOR
  - Usa lower_bound() del std::map (búsqueda eficiente O(log n))

CÓDIGO CLAVE:
  std::map<std::string, double>::const_iterator it = _database.lower_bound(date);
  // ↑ Encuentra primer elemento >= date
  
  if (it != _database.begin() && (it == _database.end() || it->first != date))
      --it;  // ← Retroceder a fecha anterior si no es exacta
  
  return (it != _database.end()) ? it->second : 0.0;
  //                                   ↑ Retorna el PRECIO

EJEMPLO:
  Usuario pide: "2011-01-05"
  _database tiene: "2011-01-03" -> 0.3, "2011-01-09" -> 0.32
  lower_bound("2011-01-05") apunta a "2011-01-09"
  Retrocedemos (--it) a "2011-01-03"
  Retornamos: 0.3
