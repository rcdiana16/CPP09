================================================================================
EJEMPLO SIMPLE: "5 4 +"
================================================================================

RESULTADO ESPERADO: 5 + 4 = 9

================================================================================
ESTADO INICIAL
================================================================================

_stack: []  (vacío)
expresión: "5 4 +"


================================================================================
PASO 1: Leer primer token "5"
================================================================================

Token leído: "5"

¿Es número? → SÍ (es un dígito del 0-9)

ACCIÓN: PUSH al stack
  - Convertir '5' a número: '5' - '0' = 5
  - _stack.push(5)

ESTADO DEL STACK:
  _stack: [5]
           ↑
         tope


================================================================================
PASO 2: Leer segundo token "4"
================================================================================

Token leído: "4"

¿Es número? → SÍ (es un dígito del 0-9)

ACCIÓN: PUSH al stack
  - Convertir '4' a número: '4' - '0' = 4
  - _stack.push(4)

ESTADO DEL STACK:
  _stack: [5, 4]
               ↑
             tope
  
  Nota: El 4 está "encima" del 5 (LIFO: Last In, First Out)


================================================================================
PASO 3: Leer tercer token "+"
================================================================================

Token leído: "+"

¿Es número? → NO
¿Es operador? → SÍ (es +, -, * o /)

ACCIÓN: Realizar operación

  PASO 3.1: Verificar que hay al menos 2 números en el stack
    _stack.size() = 2 ✓ (hay suficientes operandos)

  PASO 3.2: POP primer número (el de arriba)
    int b = _stack.top();  // b = 4 (el último que entró)
    _stack.pop();          // Sacar el 4 del stack
    
    ESTADO DEL STACK:
    _stack: [5]
             ↑
           tope

  PASO 3.3: POP segundo número (el siguiente de arriba)
    int a = _stack.top();  // a = 5 (el penúltimo que entró)
    _stack.pop();          // Sacar el 5 del stack
    
    ESTADO DEL STACK:
    _stack: []  (vacío)

  PASO 3.4: Realizar la operación
    operador = '+'
    resultado = performOperation(a, b, '+')
    resultado = performOperation(5, 4, '+')
    resultado = 5 + 4
    resultado = 9

  PASO 3.5: PUSH el resultado al stack
    _stack.push(9)
    
    ESTADO DEL STACK:
    _stack: [9]
             ↑
           tope


================================================================================
PASO 4: Fin de la expresión
================================================================================

No hay más tokens que leer.

VERIFICACIÓN FINAL:
  _stack.size() = 1 ✓ (debe haber exactamente 1 elemento)

RESULTADO:
  return _stack.top();  // return 9

RESUMEN VISUAL COMPLETO
================================================================================

Expresión: "5 4 +"

Token | Acción                    | Stack después | Explicación
------|---------------------------|---------------|---------------------------
"5"   | push(5)                   | [5]           | Apilar número 5
"4"   | push(4)                   | [5, 4]        | Apilar número 4
"+"   | b=top()=4, pop()          | [5]           | Sacar 4 (segundo operando)
      | a=top()=5, pop()          | []            | Sacar 5 (primer operando)
      | result = 5 + 4 = 9        | []            | Calcular
      | push(9)                   | [9]           | Apilar resultado
FIN   | return top()              | [9]           | Retornar 9

EJEMPLO MÁS COMPLEJO: "3 4 + 2 *"
================================================================================

RESULTADO ESPERADO: (3 + 4) * 2 = 7 * 2 = 14

Token | Acción                    | Stack después | Explicación
------|---------------------------|---------------|---------------------------
"3"   | push(3)                   | [3]           | Apilar 3
"4"   | push(4)                   | [3, 4]        | Apilar 4
"+"   | b=4, a=3                  | []            | Sacar 4 y 3
      | 3+4=7, push(7)            | [7]           | Calcular y apilar 7
"2"   | push(2)                   | [7, 2]        | Apilar 2
"*"   | b=2, a=7                  | []            | Sacar 2 y 7
      | 7*2=14, push(14)          | [14]          | Calcular y apilar 14
FIN   | return 14                 | [14]          | Resultado final


================================================================================
DETALLES IMPORTANTES DE LAS OPERACIONES DEL STACK
================================================================================

1. push(valor)
   - Añade un elemento en la CIMA del stack
   - El nuevo elemento se convierte en el "top"
   
   Ejemplo:
   _stack: [5]
   _stack.push(4)
   _stack: [5, 4]  ← 4 está arriba

2. top()
   - Retorna el elemento en la CIMA del stack
   - NO lo elimina, solo lo consulta
   
   Ejemplo:
   _stack: [5, 4]
   int x = _stack.top();  // x = 4
   _stack: [5, 4]  ← Stack sin cambios

3. pop()
   - ELIMINA el elemento en la CIMA del stack
   - NO retorna nada (void)
   
   Ejemplo:
   _stack: [5, 4]
   _stack.pop();
   _stack: [5]  ← El 4 fue eliminado


================================================================================
¿POR QUÉ EL ORDEN ES IMPORTANTE?
================================================================================

Para operaciones NO conmutativas (resta y división), el orden importa:

EJEMPLO: "5 3 -"

Token | Acción                    | Stack         | Resultado
------|---------------------------|---------------|---------------------------
"5"   | push(5)                   | [5]           |
"3"   | push(3)                   | [5, 3]        |
"-"   | b = top() = 3             | [5, 3]        | b es el SEGUNDO operando
      | pop()                     | [5]           |
      | a = top() = 5             | [5]           | a es el PRIMER operando
      | pop()                     | []            |
      | result = a - b            | []            | 5 - 3 = 2 ✓
      | result = 5 - 3 = 2        | []            |
      | push(2)                   | [2]           |

Si hiciéramos b - a sería: 3 - 5 = -2 ✗ (INCORRECTO)


================================================================================
CÓDIGO RELEVANTE EN evaluate()
================================================================================

// Cuando encontramos un operador:
if (token.length() == 1 && isOperator(token[0]))
{
    // Verificar que hay al menos 2 números
    if (_stack.size() < 2)
        throw std::runtime_error("Error: insufficient operands");
    
    // POP: Sacar los dos últimos números
    int b = _stack.top();  // ← Segundo operando (último en entrar)
    _stack.pop();          // ← Eliminar del stack
    
    int a = _stack.top();  // ← Primer operando (penúltimo en entrar)
    _stack.pop();          // ← Eliminar del stack
    
    // Realizar operación: a operador b
    int result = performOperation(a, b, token[0]);
    
    // PUSH: Apilar resultado
    _stack.push(result);
}


================================================================================
RESUMEN
================================================================================

RPN usa un STACK (pila) porque:
1. Es LIFO (Last In, First Out)
2. Perfecto para evaluar expresiones postfijas
3. Operaciones simples: push, pop, top

Algoritmo:
1. Número → PUSH
2. Operador → POP dos veces, operar, PUSH resultado
3. Al final → debe quedar 1 elemento (el resultado)

El std::stack hace todo el trabajo de gestión de memoria y orden automáticamente.
